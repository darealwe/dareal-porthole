## 站点结构

单页应用，靠 `#/` 路由切换：

1. **首屏 Hero** — 像素动态背景（WebGL）+ 大 DA REAL 字标 + 黑胶唱片
2. **关于 About** — 简介 + 悬吊工牌（吊绳 / 金属夹 / 塑料套 / 斜向反光）
3. **精选 Featured** — 16:9 卡片 + 框内取景
4. **全部作品 Works** — 真实比例瀑布流，各项目可单独指定墙封面
5. **作品详情** — 主视觉封面 + 画面组，按原图比例自适应
6. **环廊 Gallery** — 弧形横向环游，每张卡按图片真实比例定高
7. **封面层 Cover** — 唱片谢幕排版（内嵌 SVG 稿）+ 四处游走的四角游标
8. **联系 Contact** — 联系卡片 + 页脚

## 关键实现备忘

### 1. 图框口径（最终态）

| 位置 | 口径 |
| --- | --- |
| 首页精选卡 | 固定 **16:9** + 后台取景（`cropPos`） |
| 详情主视觉封面 | **原图比例自适应**，不裁切 |
| 环廊大卡 | 每张卡按图片真实比例定高，竖图超高收宽 |
| 作品墙瀑布流 | 真实比例（`MS_RATIO` 存各图宽高比） |
| 详情画面组 | 原图比例，`height:auto` |

### 2. 唱片交互

- **封面层唱片**：可鼠标**拨动**（跟手，支持多圈）+ **甩动惯性** + 指数缓动回落到底转速（14s/圈 ≈ 4.29 RPM）
- **实时转速读数**：`拖拽唱片 · DRAG TO SPIN | 4.29 RPM`
- **首屏唱片**：滚动展开时与封面层唱片**同心同径重合**（实测偏差 ≤0.01px）
  两处共用同一个角度变量，所以拨过之后滚到重合那刻纹路依旧对齐
- 命中区是 SVG 里一个透明圆，覆盖层其余区域点击穿透

### 3. 封面层装饰

- 两枚**会四处移动的四角游标**（复用页面既有 `.tfb` 蓝括号视觉）
- 按稿坐标在 12 个局部之间游走，每 2.3 秒换一处，两枚错相 5 步
- 位置经 `getScreenCTM()` 换算 → 任何视口比例都严丝合缝

### 4. 后台能力（`portfolio_admin.html`）

- 图片上传 / 排序 / 删除，**框内拖动取景**（16:9）
- **设为墙封** — 全部作品页的封面可与首页精选不同
- 站点配置：首屏标题/副标/背景图、关于简介、**工牌正面图**（可切「铺满 / 完整」适配档或切回矢量版）

> 后台读写的数据库需要 WorkBuddy 账号权限，**不登录的情况下打开只能看到空壳**。

## 部署纪律（供后续维护参考）

- 线上站由 WorkBuddy 空间托管，发布入口固定读 **`index.html`**
- 上传时**同一事务**同时传 `index.html` + `portfolio_public_v4.html` + 素材，避免「本地改了线上没改」
- 后台节点**只 commit、绝不 publish**（发布会让它变成只读，所有者反而无法写入）
- 本仓是**手动备份**，不是自动同步；改完线上站需要重新推一次
